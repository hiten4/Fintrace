# FinTrace

Financial crime detection platform: detects suspicious money movement
across connected accounts (fan-out, fan-in, layering, cycles), ranks
cases for investigation, and uses a LangGraph agent to organize
evidence for a human investigator.

> **Status:** Phase 0 (setup). Nothing is modeled yet.

## Pipeline
Transactions -> SQL + data quality + EDA -> account-transaction graph ->
graph features + anomaly detection -> risk scoring -> case ranking ->
LangGraph investigation agent -> human investigator.

## Principles
- Baseline (transaction-only) first, then graph features; one change per experiment.
- Temporal train/val/test splits only; no future leakage in graph features.
- Metrics: PR-AUC, Precision@K, case-level recall, false-positive rate.
- The agent never declares guilt. It organizes evidence and cites
  transaction IDs, and a code-based verifier checks every citation.

## Quickstart
    py -3.11 -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    pytest -q

## Limitations
The dataset is AMLSim, which is **synthetic**. Laundering patterns are
generated by known rules, so results will be optimistic compared with real
bank data and do not show real-world performance. See docs/decisions.md.
